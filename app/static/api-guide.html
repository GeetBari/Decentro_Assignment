API GUIDE

How the app talks to the server.

This page explains the API in everyday language. The dashboard already uses these endpoints for you. Open the developer tester only when you want to send requests yourself.

STEP 1

Create people

Make a person for each friend, flatmate, or traveller who will share expenses.

POST /users
STEP 2

Create a group

Make a group such as “Goa weekend”, then add those people to it.

POST /groups
POST /groups/{group_id}/members
STEP 3

Add a bill

Say what the bill was, how much it cost, and who paid. Leave splits out to divide it equally.

POST /expenses
STEP 4

Review and settle

See monthly totals, spending breakdowns, suggested repayments, then record money paid back.

GET /groups/{group_id}/analytics
GET /groups/{group_id}/settlement-suggestions
POST /groups/{group_id}/settlements

A complete example

Create a ₹1,200 dinner bill paid by Mohit and shared equally among three group members.

POST /expenses

{
  "group_id": 1,
  "paid_by": 1,
  "amount": "1200.00",
  "description": "Dinner",
  "category": "Food"
}

Result: each current member gets a ₹400.00 share.
Useful extras: GET /groups/{group_id}/monthly-summary returns one total per month, and GET /groups/{group_id}/expenses/export.csv downloads the expense history as a spreadsheet-ready CSV. All amounts are returned as decimal strings such as "1200.00". A settlement only records a payment that has already happened; it never moves money itself.
