# Demo video guide

Aim for a 75–90 second recording. The screen recording should show only the browser.

Import `docs/demo-captions.srt` into Clipchamp after recording to add the prepared captions.

| Time | Action | Highlight on screen |
| --- | --- | --- |
| 0–5 sec | Open the dashboard. | Group title and summary cards. |
| 5–13 sec | Select **Load demo data**. | Left sidebar button, then the new group. |
| 13–25 sec | Open **Add expense** and fill a short example. | Description, amount, payer, and split selector. |
| 25–37 sec | Save, then open **View split** for the new expense. | Total spent, Members card, and the share list. |
| 37–49 sec | Scroll to the monthly summary and doughnut chart. Select a chart category, then use a date filter. | Chart centre and the date filter. |
| 49–61 sec | Show **Who pays whom**, then open **Record payment**. Cancel the dialog if you do not want to change sample data. | Suggested payer, recipient, and amount. |
| 61–70 sec | Select **Export Excel**. | The export button and downloaded spreadsheet. |
| 70–78 sec | Open `/docs` in a separate browser tab. | FastAPI endpoint groups. |

## Recording tips

- Use a 1920×1080 browser window.
- Pause briefly after every click so captions remain readable.
- Zoom the browser to 100%.
- Do not show terminals, local folders, or the Codex application.
- Use a clean demo group; avoid deleting it during the recording.
